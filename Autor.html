Olá! Meu nome é Jonathan Alencar e sou o criador do projeto CineBook.

Este site foi desenvolvido com o objetivo de apresentar filmes, suas categorias e informações, proporcionando uma maneira simples de explorar diferentes produções cinematográficas.

Sobre o projeto

O CineBook é um projeto desenvolvido utilizando HTML e CSS, com páginas organizadas para apresentar filmes, detalhes das produções e cadastro.
